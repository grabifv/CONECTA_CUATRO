# Git

Qué es Git, cómo organiza archivos y versiones, y los comandos que vas a usar
todos los días.

Git es la base de todo lo que viene después: el flujo colaborativo de la
[sección de GitHub](../github/index.md) se construye directamente sobre los
commits y las ramas que se presentan aquí. Si ya conoces bien Git, puedes saltar
adelante.
