About Conecta Cuatro Arena

Connect Four (Conecta Cuatro) is played on a vertical grid, six rows by seven columns by default. Players take turns dropping a piece into a column; it falls to the lowest free cell. The first to line up four pieces — horizontally, vertically or diagonally — wins. If the grid fills up first, the game is a draw.

One source of truth

The game rules and every AI are written once, in Python. This page loads that exact code through Pyodide (Python compiled to WebAssembly) — the rules are never re-implemented in JavaScript. The same code also runs the automated tournament in GitHub Actions.

Playing well (X-ray mode)

The centre column takes part in more lines than any other, so it is the strongest opening. Beyond that, the game is about threats: three in a row with a free fourth cell. Two threats at once cannot both be blocked. Turn on X-ray during a game to see every column scored by a 5-ply search, and the column it recommends.
